# 05_대시보드 — 브랜드 인지도 진단·모니터링 대시보드

[`03_기획/대시보드_구축기획.md`](../03_기획/대시보드_구축기획.md)의 v1 범위를 실제로 구현한 것.
디자인은 무드보드 시안 3 「그린티 필드」 스타일.

## 실행

```bash
cd 05_대시보드
python -m http.server 8765     # 이후 http://localhost:8765
```

> `index.html`을 파일로 직접 열면 브라우저 보안정책(CORS) 때문에 데이터를 못 읽는다. 반드시 로컬 서버로 열 것.

## 데이터 갱신

```bash
python build_data.py           # 저장소 CSV만으로 재빌드 (오프라인)
python build_data.py --live    # NAVER 데이터랩 재조회 후 재빌드
```

- `--live`는 `C:\Users\EZ\Downloads\naver_api_streamlit_dashboard\.env`의 API 키를 사용한다.
  키는 서버 쪽에만 있고 브라우저로 내보내지 않는다.
- 실행하면 `02_수집자료/naver_datalab_2021-2026_월간.csv`·`_원자료.json`이 함께 갱신된다.
- 갱신 후 페이지를 새로고침하면 반영된다. 자산 캐시가 남으면 `index.html`의 `?v=` 값을 올린다.

## 구조

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 4개(KPI 모니터링 · 분석 재현 · 연도별 원표 · 정의/방법론) |
| `assets/style.css` | 무드보드 팔레트·타이포 규칙, 반응형(1100 / 860 / 600px), 인쇄 스타일 |
| `assets/app.js` | 데이터 렌더링 + 인라인 SVG 차트 + 해시 라우팅 (외부 라이브러리 없음) |
| `build_data.py` | 저장소 CSV → `data/dashboard_data.json` 집계 · `--live` 시 API 재조회 |
| `data/dashboard_data.json` | 대시보드가 읽는 유일한 데이터 파일 (빌드 산출물) |

## 지표 정의 (2026-08-19 팀 확정)

- **‘제주’ 연상 비중** = `이니스프리 제주` **단독** ÷ 브랜드 — 화산송이·그린티 합산 금지
- **경쟁 검색 점유율** = 3사·2사 병기, 게이트 판정은 **2사**(이니스프리+미샤)
- **브랜드 검색지수** = 일간 정밀 계열(월평균을 **일수 가중**한 1,826일 참평균)
  - 월평균 12개를 단순평균하면 폐기된 계열(8.515 · YoY −38.6%)이 나온다. `build_data.py`가 일수 가중으로 처리한다.
- 근거·계열 대조표: [`../02_수집자료/검색지수_표준수치표_2021-2026.md`](../02_수집자료/검색지수_표준수치표_2021-2026.md)

## 집계 규칙

- 마지막 월은 조회 시점에 진행 중일 수 있어 **모든 집계에서 제외**한다.
- YoY는 **같은 달끼리**(당해 1~N월 vs 전년 1~N월) 비교해 계절성을 구조적으로 통제한다.
- 상관계수 차트에는 “다른 설명 가능성” 캡션을 **항상 함께** 노출한다(상관 ≠ 인과).
