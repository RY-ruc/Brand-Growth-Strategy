‘제주’ 연상 비중 — 단독 정의

확정 2026-08-19 · 화산송이·그린티 합산 금지
읽는 법 비중이 오른 것은 제주가 늘어서가 아니라 분모(브랜드 검색)가 더 빨리 무너졌기 때문이다. 2024년 정점 이후 보합이며, 2025년부터는 제주 절대 검색도 브랜드만큼 빠진다.
회사는 제주를 뗐지만,
소비자는 아직 제주로 브랜드를 기억한다.
브랜드 검색이 5년간 −72.9% 빠지는 동안 ‘제주’ 연상 비중은 0.34%에서 0.52%로 버텼다. 다만 이 비중은 제주가 늘어서가 아니라 분모가 더 빨리 무너져 생긴 것이며, 2025년부터는 제주 절대 검색도 브랜드만큼 빠지기 시작했다 — 쓸 수 있는 동안 써야 하는 자산이다.

브랜드 검색 vs 제품군 검색 (월간)

NAVER 데이터랩 · 월간 API 계열 · 세로 점선은 주요 이벤트
스케일 주의 두 계열은 절대 크기 차이가 커서 각자의 축으로 그렸다 — 선의 높낮이를 서로 비교하지 말고 기울기(방향)만 볼 것. 실제로 제품군은 브랜드의 1/10 규모다.
리브랜딩 해에 브랜드는 −23.9%, 제품군은 +118.5%로 정반대로 움직였다. 광고선전비를 41.6% 늘린 바로 그 해다. 돈이 만든 것은 브랜드가 아니라 제품 한 줄이었다.

브랜드평판 순위

한국기업평판연구소 · 화장품전문점 카테고리(1위는 항상 올리브영)
주의 버즈량(언급량) 지표이지 소비자 선호도가 아니다. 결측월이 많아 분기 단위 경향으로만 인용하고, 순위 하락에서 미샤 상승 기여를 분리해 설명해야 한다.

매장 수 ↔ 브랜드 검색

공정위 정보공개서 · r = 0.98 (R²=0.97)
주의 상관이지 인과가 아니다. 연간 n=4로 표본이 작고, 역인과(수요 감소 → 채산성 악화 → 폐점)를 배제하지 못한다. “매장을 늘리면 검색이 는다”로 읽지 말 것.

광고선전비 ↔ 브랜드 검색

DART 감사보고서 주석21 · r = −0.03
주의 무상관(r≈0)을 “광고가 무의미하다”로 단정하지 않는다. n=5, 채널별 반응 시차 미반영. 같은 돈이 제품 검색과는 r=+0.69로 연결됐다.

NAVER 데이터랩 · 한 요청 안에서 동일 척도로 조회 · 연평균
실선 = 직접경쟁 / 점선 = 참고 같은 요청 안에서 조회했으므로 브랜드 간 크기 비교가 가능하다. 다른 조회의 값과는 절대 비교하지 말 것.

3CE를 직접경쟁으로 편입한 근거

2026-08-19 검색 데이터 실사 결과
데이터 품질 2021-01~2026-08 전 구간 결측 0. 규모도 미샤와 비교 가능한 수준이라 점유율 분모로 쓸 수 있다.
오염 검증 메타 광고 라이브러리에서는 “3CE” 단독 검색이 전세계 무관 광고로 오염됐지만, 네이버 데이터랩은 국내 검색어라 사정이 다르다. 제품 키워드(3CE 틴트·립·쿠션)와의 비율이 자연스러워 브랜드 검색으로서 신뢰할 수 있다.
맥락별 구분 메타 광고 패턴 비교에서는 원자료 규정대로 참고군 라벨을 유지한다(로드샵 채널 경쟁이 아니므로). 검색 점유율은 “소비자가 어떤 브랜드를 찾는가”를 재는 다른 질문이므로 직접경쟁으로 편입한다.

데이터 파이프라인

저장소 연결 · API 갱신
저장소 연결 — build_data.py가 02_수집자료/의 원자료 CSV(데이터랩 월간·일간)를 읽어 data/dashboard_data.json 하나로 집계합니다. 매장 수·광고선전비·상관계수·평판 순위 등 비검색 지표는 공정위·DART 확정치를 출처 주석과 함께 담습니다.
API 갱신 — python build_data.py --live 를 실행하면 NAVER 데이터랩을 최신 월까지 재조회해 02_수집자료/ CSV·JSON을 갱신하고 대시보드 데이터를 다시 만듭니다. API 키는 .env에만 두고 브라우저로 내보내지 않습니다.
주의 마지막 월은 조회 시점에 진행 중일 수 있어 모든 집계에서 제외합니다. YoY는 같은 달끼리(1~N월 vs 전년 1~N월) 비교해 계절성을 구조적으로 통제합니다.
이니스프리 브랜드 인지도 진단·모니터링 대시보드 · 시안 3 「그린티 필드」 스타일 — 리브랜딩 무드보드(베이잘트·리파인드 포레스트·스톤 베이지·동백 로즈)와 캠페인 무드보드(세이지) 팔레트 결합.
타이포 규칙 준수: 헤드라인·수치는 Noto Sans KR Black(자간 −0.05em), UI 본문은 Regular/Light, 세리프(Gowun Batang)는 브랜드 스토리 블록 한 곳으로 한정.
공개된 감사보고서·공정거래위원회 정보공개서·네이버 데이터랩·언론보도를 근거로 한 학습용 분석이며, 이니스프리 및 아모레퍼시픽과 무관한 캡스톤 프로젝트 목적의 가상 기획입니다.
