04 · 진단 재현

2023년, 돈이 만든 것은 브랜드가 아니라 제품 한 줄이었다

광고 +41.6% 증액의 해, 브랜드 검색 −23.9% · 제품군 +118.5% — 서로 다른 세 출처가 같은 지점을 가리킨다.

출처 1 · DART 감사보고서
광고 +41.6% 증액에도 브랜드 검색 −23.9%
출처 2 · 공정위 정보공개서
매장 400 → 190개 — 브랜드 검색과 r=0.98
출처 3 · NAVER 데이터랩
같은 해 제품군 검색만 +118.5%

월간 추이 — 브랜드는 무너지고, 제품군만 남았다

NAVER 데이터랩 · 월간 API 계열 · 두 선은 각자의 축(제품군은 약 1/10 규모) · 세로 점선 = 개입 시점
굵은 초록 선(브랜드)이 결론이다 — 리브랜딩(2023-02) 이후에도 계속 무너졌다. 희미한 선(제품군)만 그 해에 올랐다(+118.5%) — 돈이 만든 것은 브랜드가 아니라 제품 한 줄.

브랜드 검색 히트맵 — 5년에 걸쳐 전 구간이 식었다

NAVER 데이터랩 · 월간 API 계열 · 진한 칸 = 검색 많음 · 진행 중인 월(2026-08)은 제외
위(2021)에서 아래(2026)로 옅어진다 — 하락은 전 구간이다. 리브랜딩(2023-02, 표시) 전후로도 색의 흐름은 꺾이지 않았다 — 바꾼 것 자체보다, 바꾼 뒤에 아무것도 하지 않은 것이 문제라는 우리 주장 그대로다. YoY는 같은 달끼리 비교해 계절성 통제. 가장 진한 칸(2021-10)은 조회 구간의 검색 최고 월 — 상대지수의 기준점(100)이다.

매장 수 vs 브랜드 검색 — 같이 움직였다

공정위 정보공개서 · r = 0.98 (R²=0.97) · 시간이 왼쪽(2021)에서 오른쪽(2024)으로 흐르도록 축을 반전
읽는 법 오른쪽으로 갈수록 매장이 줄어든 해 — 점도 계단처럼 내려간다. 매장이 사라진 만큼 브랜드를 찾는 사람도 줄었다는 뜻(r=0.98). 단, 상관이지 인과가 아니다(n=4 · 역인과 배제 못 함).

광고선전비 vs 브랜드 검색 — 따로 움직였다

DART 감사보고서 주석21 · 산점도 · r = −0.03 · 2023년 점만 로즈
읽는 법 오른쪽으로 갈수록 광고비를 많이 쓴 해 — 그런데 점이 위로 가지 않는다. 돈과 브랜드 검색이 따로 움직였다는 뜻(r=−0.03). 단정 주의: n=5 · 같은 돈이 제품 검색과는 연결됐다(r=+0.69).

  3. 제품으로 남은 것은 버텼고, 이름만 남은 것은 사라졌다 — 그린티 0.31 vs 제주 0.17 (2.9배)
  4. 그린티(41.7)가 유일한 운반 수단 — 나머지 원료어를 전부 합쳐도 그 44%
금지“회사가 부르면 사람이 온다”는 반증됐다 — 레티놀 상승은 시장 성장의 결과, 몫은 하락. “제주를 그린티에 실으면 작동한다”는 가설이라고 답할 것.
