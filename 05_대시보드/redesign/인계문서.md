## 2. 노트북에서 이어서 하려면 (순서대로)

### 2-1. 저장소 받기
```bash
git clone https://github.com/RY-ruc/Brand-Growth-Strategy.git
cd Brand-Growth-Strategy
git config user.name xio
git config user.email rla02240@gmail.com
```

### 2-2. gh CLI 인증 (푸시에 필요)
```bash
gh auth login
```
- `GitHub.com` → `HTTPS` → `Login with a web browser` → **axiokr 계정으로 승인**
- 이 PC에서는 Windows 자격증명에 다른 계정이 캐시돼 푸시가 403 났던 적 있음 → 그때는 `gh auth setup-git` 실행

### 2-3. 로컬에서 열기
```bash
python -m http.server 8765
```
→ http://localhost:8765/05_대시보드/redesign/
(파일 더블클릭으로 열면 폰트가 CORS로 막힘. 반드시 로컬 서버)

### 2-4. 수정 → 배포
`05_대시보드/redesign/index.html`을 직접 고친 뒤:
```bash
git add 05_대시보드/redesign/index.html
git commit -m "수정 내용"
git push origin main
```
푸시 후 1~2분 뒤 Pages 자동 반영. 확인은 `?v=숫자`를 붙여 캐시 우회.

## 8. 작업하며 실제로 났던 사고 (반복 금지)

1. **깃허브 포크를 만들어 기록을 어지럽힘** → 팀 리포에 직접 커밋하는 게 맞음. 만들었던 포크 2개는 삭제 완료
2. **커밋 작성자가 axiokr로 찍힘** → `git config user.name xio` 설정 필수
3. **폰트 경로** — 시안을 `05_대시보드/redesign/`에 두면 `../../00_무드보드/...`가 맞음 (한 단계 깊음)
4. **산점도 x축 역순** — 매장 수처럼 감소하는 지표는 축을 반전해야 시간이 왼→오로 흐름
5. **헤드라인 서체를 산세리프로 바꿨다가 반려** — 무드보드 기준은 곰운바탕
6. **"중요한 건 크게"를 숫자 키우기로 오해** — 마케터 기준은 설득력이지 크기가 아님
