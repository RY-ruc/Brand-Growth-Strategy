## Part 1. 왜 이 제안인가 — 진단 요약

큰 그림을 만드는 숫자만 본문에 남긴다.

- 국내 브랜드 검색지수 -23.9%(2023) → -38.6%(2024)
- 광고선전비와 브랜드 검색의 상관 **r=-0.03**(무상관) — 돈이 목표에 닿지 못했다는 가장 강한 한 장짜리 증거
- 매장 수와 브랜드 검색의 상관 **r=0.98** — 노출 접점이 줄어든 만큼 인지도도 줄었다

> 표본 크기, "다른 설명 가능성"(K뷰티 붐 혼재, 역인과 가능성 등), 연도별 세부 수치는 **부록 — 분석 파트**에서 다룬다.

## Part 4. 크리에이티브 제안 (Before / After)

[`크리에이티브제안_근거매핑.md`](크리에이티브제안_근거매핑.md)의 축 A(인지도 이탈)·축 B(제로클릭 대응)에서 도출. 4개로 구성한다 — **오프라인 체험 거점이 실증 사례 확인으로 새로 추가됐다.**

### 4-1. 무드보드
| | Before | After |
|---|---|---|
| 근거 | 메타 광고 라이브러리 기반 재구성(성과형·제품나열형), 광고 220건 중 헤리티지 서사 0건 | Part 3 문장에서 도출 — 제주 연관 검색 비중 상승(0.79%→1.87%)이 근거 |
| 자료 | `무드보드/이니스프리_현재브랜드방향_무드보드.html` | `무드보드/이니스프리_리브랜딩_무드보드.html`(헤리티지 계승 톤) 또는 `이니스프리_캠페인_무드보드.html`(휴면고객 재활성화 톤, "오랜만이에요") 중 타깃에 맞게 선택 — **둘 다 이미 시안으로 존재** |

### 4-2. 오프라인 체험 거점 (신규)
| | Before | After |
|---|---|---|
| 근거 | 매장 수-브랜드 검색 상관 r=0.98, 매장 400→190개, 판매 중심 매장이 그대로 축소되는 중 | **이미 존재하는 실증 사례를 확장** — '공병공간'(80년 한옥 개조, 공병 23만개 마감재, 2003년부터 22년째 이어온 그린사이클 캠페인) |
| 자료 | 일반 매장 현황(축소 추세) | '공병공간' 사례 기반 확장안 — 신규 제작이 아니라 **기존 성공 사례의 재조명·확대** |
| 비고 | 이 항목은 새로 만드는 제안이 아니라, **이미 있는데 소비자가 거의 모르는 자산을 앞으로 꺼내는 것.** 설득력이 가장 강한 Before/After가 될 수 있다 |

### 4-3. 랜딩페이지
| | Before | After |
|---|---|---|

| 자료 | 현재 메인페이지 캡처 | 목업/프로토타입 — **신규 제작** |

| 자료 | 현재 대표 제품 상세페이지 캡처 | 목업 — **신규 제작** |

## Part 5. 실행 로드맵 — 난이도별 8개 제안 + 대시보드

[`마케팅제안_전체스캔.md`](마케팅제안_전체스캔.md)에서 나온 8개 제안(독립 검증 완료)을 착수 난이도로 배치한다. Part 4가 "무엇을 보여줄지"라면, 이건 "무엇을 언제 시작할지"다.

| 시점 | 제안 | 비고 |
|---|---|---|
| **즉시 착수(낮은 난이도)** | 자사 채널 전체 감사(공식 사이트+SNS), 플랫폼 제휴 기획전 확대(무신사 등) | 예산 승인 없이 30일 안에 시작 가능 |
| **중기(중간 난이도)** | 콘텐츠 일부 전문가 검증형 전환, 올리브영 랭킹 침투 KPI화, 휴면고객 재활성화 캠페인(4-1 무드보드와 연동) | 60~90일 |
| **장기·조직 차원** | 오프라인 체험 거점 확장(4-2와 연동, '공병공간' 모델), 코스알엑스 운영 노하우 이식 검토(그룹 협의 필요) | 예산·조직 승인 필요, 3년 로드맵에 편입 |

- 예산: 재배치 아닌 증액, 최소 3년 사전 확약 (Part 1의 "1년 만에 축소" 반복 방지가 핵심 논거)
- **"약속을 지키는지는 아래 모니터링 파트(대시보드)로 계속 보여준다"** — 상세 KPI·게이트 기준표는 **부록 — 모니터링 파트**로 이동
