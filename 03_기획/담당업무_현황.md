## 스케줄러 업무 상세 (xio 담당)

**하는 일은 명령 두 개 실행하고 푸시하는 것이 전부입니다.**

```bash
cd 05_대시보드
python build_data.py --live     # 검색 데이터 최신 월까지 재조회
python check_aeo.py             # 공식몰 AEO 4항목 실측
git add -A && git commit -m "데이터 갱신 YYYY-MM-DD" && git push
```

- 푸시하면 1~2분 뒤 대시보드 사이트에 자동 반영됩니다.
- **주기는 월 1회면 충분합니다.** 데이터랩은 월간 지표라 월이 바뀌어야 새 값이 생깁니다.
  단 AEO는 유동적이므로(llms.txt가 조사 당일 오후에 갱신된 사례) 발표 직전에 한 번 더 돌리세요.
- 실행 후 대시보드 「변화 이력」 화면에서 직전 대비 무엇이 바뀌었는지 확인할 수 있습니다.

### 확인이 필요한 것 — 자동화하면 이 업무 자체가 없어집니다

GitHub Actions로 매월 자동 실행하게 만들 수 있습니다. 그러면 사람이 손댈 일이 없습니다.
**단 NAVER API 키를 저장소 Secret에 등록해야 하고, 그건 저장소 소유자(RY) 권한입니다.**

| | 수동(현재) | 자동화 |
|---|---|---|
| 손이 가는 일 | 월 1회 명령 2개 + 푸시 | 없음 |
| 필요 조건 | 없음 | RY가 GitHub Secret에 API 키 등록 |
| 위험 | 실행을 잊으면 데이터가 멈춤 | 키가 저장소 설정에 저장됨(코드에는 노출 안 됨) |

> **결정 필요**: 자동화할지 수동 유지할지. 마감까지 10일뿐이라 **수동으로 두고 발표 직전 한 번 돌리는 것**으로 충분합니다.
