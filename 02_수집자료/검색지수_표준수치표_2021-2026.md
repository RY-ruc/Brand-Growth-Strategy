# 검색지수 표준 수치표 (2021–2026)

- 확정 2026-08-19 · 문서 간 수치 통일의 단일 기준
- 배경: 같은 네이버 데이터랩 데이터를 **세 가지 방식으로 집계**한 값이 문서마다 섞여 쓰여 소수점 불일치(-38.6/-38.5/-38.4% 등)가 발생했다. 원인을 전량 재계산으로 특정하고 표준을 정한다.

## 표기 규칙 (확정)

1. **일간 정밀 계열을 기본으로 쓰고, 월간 API 계열을 병기한다.** (팀 결정 2026-08-19)
2. 단순평균 계열(6.920/5.266/-38.6%)은 **신규 사용 금지** — 일 수 미가중이라 부정확. 기존 문서에 남은 값은 계열 라벨로 식별한다.
3. 표·문서에는 어느 계열인지 명시한다. 발표 구두 표현은 "-38%대", "약 -29%"처럼 반올림 허용.

## 경쟁 검색 점유율 (KR4) — 재산출 표준

**팀 결정(2026-08-19): 3사·2사 둘 다 표기하고, 게이트 판정은 2사 기준.**

| 연도 | 3사 (이니+미샤+토니) | 2사 (이니+미샤) |
|---|---|---|
| 2021 | 61.1% | 70.8% |
| 2022 | 58.4% | 70.3% |
| 2023 | 51.5% | 62.3% |
| 2024 | 46.1% | 64.4% |
| 2025 | **41.1%** ← baseline | **60.9%** ← baseline |
| 2026 (1~7월) | 43.8% (토니모리 붕괴 착시 +2.7%p) | 59.0% (착시 없는 실제 — 하락 지속) |

- 산출: 연평균 지수 비율. 월별 점유율 평균 방식과 ±0.5%p 이내로 동일. 구 CSV(2021-2025)와 신 CSV(2021-2026) 모두에서 동일 값 재현 확인
- ⚠ **[대시보드_구축기획.md](../03_기획/대시보드_구축기획.md) 0-1장의 구 시계열 56.5→38.5%는 저장소의 어떤 데이터·방식으로도 재현되지 않는다** — 작성자(RY) 확인 필요. 재현 가능한 위 표로 교체함
- 2사 지표가 말해주는 것: 3사 점유율은 2026년에 "올라" 보이지만(43.8%) 2사로 보면 **여전히 하락 중**(60.9→59.0%) — 착시 제거 효과의 실례
