## 새로 만들 때 반영할 것

1. **서사는 [`핵심발견_발표용.md`](../01_분석결과/핵심발견_발표용.md)가 정본** — "제주를 버렸다"를 현재형으로 쓰면 금지 표현에 걸립니다
2. **AEO는 4/4** — 확정 서술은 「형식은 4/4 완비, 그런데 실제 AI 답변에는 안 나온다」. "대응 전무"는 발표에서 즉사 지점
3. **「zero-click 69%」는 출처를 찾거나 빼기** — 저장소 어디에도 근거가 없습니다
4. **팔레트는 확정판(#253531 계열)** — 구판(#24382C)과 이름은 같고 값이 다릅니다
5. **수치는 표준수치표 기준** — 계열이 다르면 반드시 명시(2024 브랜드 YoY −38.4/−38.5/−38.6%는 전부 집계 방식 차이)
6. pptx가 필요하면 텍스트 덤프 금지 — html 슬라이드를 이미지로 넣거나 실제 슬라이드 개체로 제작
