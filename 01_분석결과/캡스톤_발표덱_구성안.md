# 캡스톤 발표덱 구성안

- 작성 2026-08-20
- **발표 20분 + 질의응답 10분**
- 기존 [`발표덱.html`](발표덱.html)은 **강사님 진행보고용**이라 별도. 이 문서는 캡스톤 발표용 새 덱의 설계다.

## 설계 원칙

1. **결론을 먼저 말한다.** 20분에 빌드업을 쌓으면 결론에서 시간이 없다.
2. **문제 → 시장 → 문장 → 화면 → 실행 → 측정** 순서. 제안서 Part 구조 그대로라 청중이 길을 잃지 않는다.
3. **질의응답 10분을 위한 백업 슬라이드를 따로 만든다.** 이 팀의 강점은 근거 등급·한계 명시·정의 확정 과정이다. 본편에서는 결론만 말하고, 질문이 나오면 백업에서 근거를 꺼낸다.
4. 장당 40~50초 기준 → **본편 26장 안쪽**.
