# 고민어 vs 원산지어 — "사람들은 제주로 검색하지 않는다"는 반론 검증

- 재현 [`고민어_vs_원산지어.py`](../02_수집자료/고민어_vs_원산지어.py)
- **계열 주의** — 데이터랩 지수는 **같은 요청 안에서만** 비교 가능. A·B·C는 각각 별도 요청이다.
  A표 값과 B표 값을 서로 빼거나 나누지 말 것. [`롱테일_키워드_검증.md`](롱테일_키워드_검증.md)의 값과도 섞지 말 것

## 검증한 반론

> "사람들은 제주·그린티·화산송이로 검색하지 않는다.
> 건성·지성·저자극·여드름성처럼 **자기 피부 고민**으로 검색한다.
> 그러면 제주를 아무리 홍보해도 검색이 안 될 텐데 의미가 있나?"

**팀 내부에서 나온 반론이며, 심사에서도 나올 가능성이 가장 높은 질문이다.**

---

## 결론 세 줄

1. **반론은 맞다.** 원료 × 고민 결합어는 0.086~0.935, 맨단어 `화산송이`는 **1.885**로 사실상 없다.
   **원료어·원산지어를 진입 키워드로 삼는 전략은 폐기한다**
2. **그러나 결론은 뒤집힌다** — 회사가 부른 순서와 소비자가 찾는 순서가 **정확히 일치**한다
   (레티놀 75.168 → 노세범 30.426 → 그린티 18.172 → 제주 8.206). **제주가 작은 것은 회사가 안 불러서다**
3. **그린티(18.172)가 제주(8.206)의 2.2배다.** 제주를 직접 밀지 말고 **그린티를 통해 실어 보낸다**

## ⚠ 1차 해석은 틀렸다 — 반드시 읽을 것

이 문서 A·B표만 보고 **“사람들은 고민어로 검색하지 않는다”고 결론냈던 것은 오류다.**

`저자극 스킨케어`·`피지 조절`은 **아무도 쓰지 않는 어색한 표현**이라 작게 나온 것이지,
고민어가 약해서가 아니다. **맨단어로 다시 재니 정반대였다**(D표).

| 1차 해석(틀림) | 재검증(D표) |
|---|---|
| 피지 조절 3.075 < 화산송이 21.223 → “재료어가 이긴다” | **여드름 22.452 · 모공 8.321 > 화산송이 1.885** |

> **교훈 — 어떤 표현을 대표로 고르느냐가 결론을 뒤집는다. 맨단어로 한 번 더 확인할 것.**
> **발표에서 “사람들은 고민어로 검색하지 않는다”고 말하면 그 자리에서 무너진다.**

## A. 피부고민 언어 — 반론의 근거

| 축 | 구성 키워드 | 지수 |
|---|---|---:|
| **건성·수분** | 건성 스킨케어, 속건조 크림, **수분크림 추천** | **58.251** |
| **여드름·트러블** | 여드름 화장품, 트러블 케어 화장품, 여드름 크림 | **44.560** |
| 지성·수부지 | 지성 스킨케어, 수부지 크림, 지성피부 크림 | 9.007 |
| 예민·민감 | 민감성 화장품, 예민피부 크림, 진정 크림 | 7.643 |
| **저자극·순한** | 저자극 스킨케어, 순한 화장품, 저자극 크림 | **1.210** |
| 합계 | | 120.671 |

**해석 — 고민어 안에서도 갈린다.**

- 큰 축(58.3 · 44.6)은 `수분크림 추천`·`여드름 크림`처럼 **구체적인 제품 이름**을 품고 있다
- 순수한 상태 표현(`저자극` 1.2 · `예민` 7.6 · `지성` 9.0)은 작다

> **"사람들은 고민어로 검색한다"가 아니라 "사람들은 살 물건 이름으로 검색한다"가 정확하다.**

## B. 노세범은 왜 컸나 — 브랜드어가 카테고리어를 대체한 사례

| 축 | 구성 키워드 | 지수 | 성격 |
|---|---|---:|---|
| **노세범** | 노세범, 이니스프리 노세범 | **66.784** | 브랜드어 |
| **기름종이** | 기름종이 | 63.770 | **일반 카테고리어** |
| 그린티 | 이니스프리 그린티, 그린티 세럼 | 29.108 | 원료어 |
| 화산송이 | 화산송이, 이니스프리 화산송이 | 21.223 | 원료어 |
| 피지 조절 | 피지 조절, 피지 컨트롤 | 3.075 | 추상 고민어 |

### ★ 이 표가 이 문서에서 가장 중요하다

`노세범`은 **`기름종이`가 있던 자리를 차지한 제품**이다. 무관한 카테고리가 아니라 **직접 대체 관계**다.

```
피지 조절     3.075   ← 추상 고민어. 아무도 이렇게 검색하지 않는다
기름종이     63.770   ← 이 고민을 해결하던 일반 카테고리어
노세범       66.784   ← 브랜드어가 그것을 넘어섰다
```

> **제네릭 브랜드화는 이니스프리에서 이미 완료됐다. 노세범 하나에서.**

**기존 비교(노세범 70.126 vs 선크림 59.758)보다 이 비교가 강하다.**
선크림은 노세범이 대체한 카테고리가 아니어서 "무관한 것을 비교했다"는 반론이 가능했다.
→ 발표에서는 **기름종이 비교를 쓸 것.** (단 두 수치는 별도 조회이므로 한 슬라이드에 섞지 말 것)

## 그래서 전략이 어떻게 바뀌나

### 폐기하는 것

> ❌ **`제주 그린티 수분크림` 같은 결합어를 타겟 키워드로 삼는다** — 실측 0.511. 노려도 아무 일도 일어나지 않는다.

이 표현은 [`핵심발견_발표용.md`](핵심발견_발표용.md)에서 삭제했다. **발표에서 예시로 들지 말 것.**

### 유지하는 것 — 운반 수단이 그린티다

```
사람이 들어오는 문   →  "수분크림" 62.98         ← 일반명사. 진입은 여기서만 일어난다
살 물건            →  "이니스프리 그린티" 41.74  ← 살아있는 유일한 헤리티지 제품
왜 이걸 사나        →  제주 서귀포 녹차밭 20년    ← 여기서 이긴다
```

**이니스프리 그린티 = 제주 서귀포 녹차밭 원료다. 그린티와 제주는 경쟁 관계가 아니다.**

`제주 화장품`으로 광고하면 아무도 안 찾는다.
**`이니스프리 그린티 — 제주 서귀포 녹차밭 20년`이면 그린티를 타고 제주가 실려 간다.**

> **“제주로 돌아가자”가 아니라 “제주를 그린티에 실어서 팔자”다.**

- **AI는 키워드를 대조하지 않고 문서를 읽고 인용 여부를 판단한다** →
  제주가 검색어가 아니어도 **인용 근거로는 작동한다**
- 실제로 `녹차 스킨케어 추천`에 이니스프리가 나온다. 누가 "녹차"를 검색해서가 아니라
  **20년간 축적된 서술 때문**이다
- 경쟁사도 임상 데이터·저자극은 낸다. **제주 20년 원산지는 이니스프리만 낸다** — 동점을 깨는 근거

### 네이밍에 주는 함의 — 순서가 반대면 실패한다

| | 노세범 | 제주·그린티·화산송이 |
|---|---|---|
| 이름이 말하는 것 | **고민 해결** (no sebum = 피지 없음) | **원산지·원료** |
| 진입 검색어가 되나 | ✅ 66.784 | ✗ 결합어 0.2~0.9 |

> **이름은 고민의 언어로, 근거는 제주로.**
> 원산지를 이름에 붙이는 것으로는 검색을 만들지 못한다 — 결합어 실측이 그것을 보여준다.

## 인용 시 주의

- A·B·C는 **각각 별도 요청**이다. 표를 가로질러 값을 비교하지 말 것
- 각 축은 **묶음 조회**이므로 인용할 때 구성 키워드를 반드시 함께 밝힐 것
- 조회 구간은 2025-08 ~ 2026-08. 다른 문서의 2021~2026 시계열과 절대값을 섞지 말 것
- **`비자림·동백` 36.682는 어디에도 쓰지 말 것**
- `녹차 진정·수분`(0.086)은 13개월 중 5개월이 결측이다. "0에 가깝다" 이상으로 해석하지 말 것
