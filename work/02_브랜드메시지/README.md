## 이 폴더가 답해야 할 질문

> **2023년 리브랜딩에서 정확히 무엇을 버리고 무엇을 얻으려 했는가?**

재무 데이터는 *"돈을 쓰고 실패했다"* 까지만 증명한다.
**무엇을 버려서** 실패했는지는 이 폴더가 증명해야 한다. **이 분석의 빠진 절반이다.**
