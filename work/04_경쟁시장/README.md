## 이 폴더가 답해야 할 질문

> **매출 하락이 리브랜딩 탓인가, 로드샵 채널이 무너진 탓인가?**

**이 둘을 분리하지 못하면 분석 전체가 무너진다.** 심사에서 가장 먼저 들어올 반론이다.

## 상태 — 🔶 근거 1건 확보, 보강 필요

이미 확보된 대조군 (2024년)

| 브랜드 | 매출 | 영업이익 |
|---|---|---|
| **이니스프리** | **-18.0%** | **-84.1%** |
| 토니모리 | +23.8% | +66% |
| 에이블씨엔씨 | — | +53% |

같은 채널에서 **이니스프리만 빠졌다.** 리브랜딩 가설의 가장 강한 근거다.

> ⚠ **단, 보도상 경쟁사 성장 원인은 "해외 공략"이다.** 그대로 인용하면 반박당한다.
> **"국내 성과만 비교하면"** 이라는 조건을 붙이거나, 아래 #1로 국내분을 분리해야 한다.

## 모아야 할 것

| # | 자료 | 어디서 | 왜 |
|---|---|---|---|
| 1 | **토니모리·에이블씨엔씨 감사보고서** | DART | 국내/해외 매출 분리 → 조건 없이 비교 가능 |
| 2 | 로드샵 전체 매장 수 추이 2021~2025 | 업계 보도 | 채널 붕괴의 규모 |
| 3 | 같은 시기 리브랜딩한 다른 뷰티 브랜드 | 보도 | 성공 사례가 있으면 대조군 강화 |
| 4 | 채널별 앱 MAU (2026.2) | 이미 확보 — 올영 934만 / 무신사 765만 / 다이소몰 516만 / 컬리 450만 | 시장 지형 배경 |
