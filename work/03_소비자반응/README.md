# 03. 소비자 반응

**담당**: 【 】

## 이 폴더가 답해야 할 질문

> **소비자에게 리브랜딩이 도달했는가? 제주라는 자산은 실제로 있었는가?**

## 상태 — ⬜ 미착수

## 모아야 할 것

| # | 자료 | 어디서 | 왜 |
|---|---|---|---|
| 1 | **"이니스프리 제주" 검색량 2021~2025** | 네이버 데이터랩 (무료) | 제주가 자산이었는지 / 언제 꺼졌는지 |
| 2 | "이니스프리" 검색량 2021~2025 | 네이버 데이터랩, 구글 트렌드 | 브랜드 관심도 전체 추이 |
| 3 | 올리브영 리뷰의 **자연주의·제주 언급 빈도** | 올리브영 | 소비자 인식 변화 |
| 4 | 리브랜딩 당시 커뮤니티 반응 | 디시·더쿠·블로그 (2023년 전후) | 정성 근거 |

## 이게 왜 중요한가

검색량 그래프에서 **2023년을 기점으로 "제주" 연관 검색이 꺾인다면**, 재무 데이터(광고비 +41.6% → 매출 -8.7%)와 맞물려
**"돈을 쓰면서 오히려 자산을 지웠다"** 는 결론이 완성된다.

반대로 **꺾이지 않는다면** 팀의 가설을 수정해야 한다. 그것도 중요한 발견이다.

## 완료 기준

> **검색량 추이 그래프 1장 + 2023년 전후 비교 수치**

## 주의

- ⚠ **리뷰 수집 전 반드시 대상 사이트의 이용약관과 robots.txt를 확인할 것.** 확인 없이 모으면 나중에 통째로 버려야 한다
- 네이버 데이터랩은 **상대지수(0~100)** 다. 절대 검색 횟수가 아니므로 "몇 건"이라고 쓰지 말 것
- 커뮤니티 캡처에 **작성자 닉네임·프로필이 찍히지 않게** 할 것 (public 저장소)
